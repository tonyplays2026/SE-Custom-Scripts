[h1]Robotic Arm Controller[/h1]
Controls sequences of pistons, rotors, and hinges — plus optional welders, projectors, and spotlights — via named positions and automated sequences. Designed for multi-step robotic arm routines that need to run unattended and survive world reloads mid-sequence.

[h2]Setup[/h2]
[list]
[*]Paste the script into a Programmable Block and click [b]Check Code[/b].
[*]Define your positions and sequences in the block's [b]Custom Data[/b] (format below).
[*]Recompile after any Custom Data changes.
[/list]

[h2]Custom Data Format[/h2]
[code]
[settings]
debug=false

[sequences]
deploy=home:extended
retract=extended:home

[home]
Piston Base:Piston:0.0:0.5
Main Rotor:Rotor:0.0:5.0
Arm Hinge:Hinge:90.0:5.0

[extended]
Piston Base:Piston:5.0:0.5
Main Rotor:Rotor:45.0:5.0
Arm Hinge:Hinge:45.0:5.0
Welder 1:Welder:true
[/code]

[b]Section headers[/b]
There are two headers that are reserved key words: settings and sequences.  All other headers are treated as positions/actions.  Any line starting with # is considered a comment and will not be loaded when the config is parsed.

[b]Settings[b]
[table]
[tr][th]Setting Name[/th][th]Setting Values[/th][th]Notes[/th][/tr]
[tr][td] debug [/td][td] true | false [/td][td] Turns on debug logging [/td][/tr]
[/table]

[b]Sequences[/b]
[code]SequenceName=position1:action1:position2[/code]
Each step waits for all blocks in that position/action to complete before advancing to the next step.

[b]Positions and Actions[/b]
[code]BlockName:BlockType:Value1:Value2:Value3[/code]
Block names must exactly match the in-game names.
[table]
[tr][th]BlockType[/th][th]Value1[/th][th]Value2[/th][th]Value3[/th][th]Notes[/th][/tr]
[tr][td] Piston [/td][td] Target Position in meters [/td][td] Velocity in m/s [/td][td] --- [/td][td] --- [/td][/tr]
[tr][td] Hinge [/td][td] Target Position in degrees [/td][td] Velocity in m/s [/td][td] --- [/td][td] --- [/td][/tr]
[tr][td] Rotor [/td][td] Target Position in degrees [/td][td] Velocity in m/s [/td][td] AUTO | CW | CCW [/td][td] Default is auto allowing the game to decide which direction to rotate.  CW = clockwise  CCW = counter-clockwise [/td][/tr]
[tr][td] Welder [/td][td] true | false [/td][td] --- [/td][td] --- [/td][td] Turns welder on or off[/td][/tr]
[tr][td] Projector [/td][td] true | false [/td][td] --- [/td][td] --- [/td][td] Turns projector on or off[/td][/tr]
[tr][td] Light [/td][td] true | false [/td][td] --- [/td][td] --- [/td][td] Turns light on or off[/td][/tr]
[/table]

[h2]Commands[/h2]
Pass these as the Programmable Block argument — via the run command.
[table]
[tr][th]Command[/th][th]Argument[/th][th]Notes[/th][/tr]
[tr][td] sequence [/td][td] Sequence name defined in CustomData [/td][td] Runs the sequence to completion [/td][/tr]
[tr][td] Position | Action name [/td][td] -- [/td][td] Moves to, or completes, based on defintion in CustomData [/td][/tr]
[tr][td] stop [/td][td] -- [/td][td] Halts any movement in progress and clears the active sequence [/td][/tr]
[/table]

[h2]Reload and Recompile Behavior[/h2]
The active sequence and current step are saved automatically. On world reload or PB recompile the script resumes exactly where it left off, resending move commands to all blocks in the current step.

[h2]Notes[/h2]
[list]
[*]A step times out after [b]60 seconds[/b] if the target position is never reached. The sequence stops and a warning is printed. The timeout is configurable via [b]MOVE_TIMEOUT_SECONDS[/b] at the top of the script.
[*]Position tolerance is [b]0.05[/b] (meters for pistons, degrees for rotors/hinges). Configurable via [b]TOLERANCE[/b] property in script.
[*]Config errors are printed to the detail panel line by line — a bad line is skipped, not the entire config.
[*]Enable [b]debug=true[/b] in [b][settings][/b] to print per-block status on every check tick. Disable it for normal operation.
[/list]
